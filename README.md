# Boolean Bench

Boolean Bench is a labelled-row query builder for literature searches. You build a search one row at a time, choosing a field, an operator and terms for each, and it compiles the rows into correctly bracketed Scopus and Web of Science advanced-search syntax. It also includes field-code and syntax references and a journal-source picker.

**Live:** https://mmille105.github.io/boolean-bench/

It is a single self-contained HTML file that runs entirely in the browser. There is no server and no account. The only thing it stores is your current search and theme, kept in the viewer's own browser local storage.
